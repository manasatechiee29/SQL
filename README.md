**SQL Portfolio – Mini Projects & Business Case Studies**

1. Project Overview

Welcome to my SQL Portfolio!

This repository showcases my hands-on experience in SQL through industry-oriented mini projects, business case studies, analytical queries, and real-world problem-solving scenarios.

The objective of this repository is to demonstrate how SQL can be used to extract, transform, analyze, and interpret structured business data to support data-driven decision-making.

The repository covers multiple business domains, including Banking, Insurance, Automotive, FMCG and E-commerce.

It includes practical SQL implementations ranging from fundamental queries to advanced analytical techniques.
